# Computational Math & Applied Calculus Scripts

## Overview
This repository contains numerical analysis implementations, applied differential calculus evaluations, and signal analysis plotting scripts created using GNU Octave and MATLAB.

## Key Features & Highlights
* **Piecewise & Limits Analysis**: Modeled three-segment piecewise linear functions, solved algebraic limits, and determined parameter values for function continuity and differentiability.
* **Applied Derivatives & Optimization**: Evaluated exponential/logarithmic differentiation, tangent line equations, and stationary critical points for structural beam load distributions.
* **Trigonometric Signal Plotting**: Plotted rational trigonometric signal functions and conducted first-derivative asymptotic boundary analysis in GNU Octave.
